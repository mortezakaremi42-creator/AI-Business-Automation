# نُوا — پایانه دمو و موتور مدیریت معامله

رابط موبایلی فارسی + سرویس Node.js برای **معامله آزمایشی Spot**. موتور از تاریخچه خروج‌های نهایی‌شده آمار می‌سازد، کارمزد را از هر سمت معامله کم می‌کند و قواعد حد ضرر/سود را روی قیمت‌های دریافت‌شده اعمال می‌کند.

## اجرا

پیش‌نیاز: Node.js 20 یا جدیدتر (بدون وابستگی npm).

```bash
npm test
npm start
```

سپس `http://127.0.0.1:4173` را باز کنید. برای پیش‌نمایش داخل محیط توسعه:

```bash
npm run dev
```

برای نصب PWA در اندروید، از Chrome و HTTPS یا localhost استفاده کنید و «Install app / افزودن به صفحه اصلی» را بزنید. داده‌های موتور در حافظه نگهداری می‌شوند و با راه‌اندازی مجدد سرور پاک می‌شوند؛ این نسخه دیتابیس پایدار یا حساب کاربری ندارد.

## اصلاحات و منطق

- Win Rate = معاملات بسته‌شده با خالص PnL مثبت / تعداد کل معاملات بسته‌شده. موقعیت‌های باز از مخرج و صورت کنار گذاشته می‌شوند؛ PnL صفر برد به حساب نمی‌آید.
- خالص معامله = سود ناخالص منهای کارمزد ورود و کارمزد خروج واقعی. تنظیم پیش‌فرض ۰٫۲٪ برای هر سمت است (۰٫۴٪ رفت‌وبرگشت در قیمت/حجم برابر).
- معاملات Spot لانگ: حد محافظ ۵٪ از ورود؛ پس از رشد، Trailing Stop با فاصله ۳٪ از سقف؛ دو برداشت سود ۱۰٪ و ۲۰٪ هرکدام ۳۰٪ از حجم اولیه.
- Drawdown روزانه بر مبنای Equity ابتدای روز و سود/زیان تحقق‌یافته و تحقق‌نیافته بررسی می‌شود؛ در آستانهٔ ۳٪ موتور متوقف، پوزیشن‌های دمو بسته و شروع مجدد تا ۲۴ ساعت قفل می‌شود.
- RSI و MACD فقط روی کندل‌هایی محاسبه می‌شوند که فراخواننده صراحتاً `closed: true` داده باشد.
- موتور دمو سفارش با انحراف بیش از ۰٫۳٪ نسبت به قیمت مرجع را رد می‌کند. در لایهٔ Adapter، الگوی IOC محدودکنندهٔ قیمت برای quote زنده پیاده شده است.
- توقف اضطراری در دمو همهٔ موقعیت‌ها را با آخرین قیمت شبیه‌سازی‌شده می‌بندد، سفارش‌های معلق دمو را پاک و توقف را تا بازنشانی صریح قفل می‌کند.

## محدودیت حیاتی حالت واقعی

**این نسخه به Bit24 وصل نیست و معاملهٔ واقعی را فعال نمی‌کند.** کلید Demo/Real فقط تلاش برای تغییر حالت را رد می‌کند. هیچ endpoint، قالب امضا یا مجوز اختصاصی Bit24 حدس زده نشده، چون قرارداد رسمی API در ورودی پروژه وجود ندارد. فایل `lib/bit24-adapter.mjs` یک مرز fail-closed و تست‌های slippage/permissions دارد، اما transport واقعی عمداً وجود ندارد؛ ازاین‌رو توقف اضطراری فعلی فقط روی حساب دمو کار می‌کند.

پیش از اتصال واقعی باید مستندات رسمی و جاری Bit24 برای احراز هویت/امضا، مجوز Spot، فرمت نماد/دقت حجم و قیمت، IOC، لغو سفارش، موجودی آزاد، rate limit و پاسخ‌های partial-fill تأیید و adapter مستقل بازبینی امنیتی شود. فقط پس از آن می‌توان live mode را فعال کرد. API key/secret نباید به مرورگر، repository یا فایل‌های عمومی وارد شوند؛ در استقرار واقعی از secret manager استفاده کنید و مجوز Withdraw/Transfer را خاموش نگه دارید. نمونهٔ متغیرها در `.env.example` صرفاً توضیحی است و اسراری در آن نیست.

## API دمو

- `GET /api/status` — موجودی، Equity، آمار بسته‌شده، موقعیت‌ها و وضعیت قفل
- `POST /api/trades` — خرید Spot دمو (`symbol`, `quantity`, `price`, `referencePrice`)
- `POST /api/prices` — ارسال قیمت نمونه برای اجرای توقف‌ها و برداشت‌های پله‌ای
- `POST /api/positions/:id/close` — بستن موقعیت دمو
- `POST /api/demo/cash` — واریز/برداشت مجازی
- `POST /api/panic`، `/api/panic/reset` — توقف اضطراری دمو و بازنشانی قفل
- `POST /api/indicators` — RSI/MACD از آرایه کندل‌های بسته‌شده
- `POST /api/mode` — فقط `PAPER` پذیرفته می‌شود؛ `REAL` با 403 رد می‌شود

این پروژه زیرساخت نمایشی/آزمایشی است، نه سامانهٔ آمادهٔ مدیریت پول واقعی یا توصیهٔ سرمایه‌گذاری. پیش از استفادهٔ مالی، persistence تراکنشی، احراز هویت، audit log، مانیتورینگ، recovery و تست‌های exchange sandbox لازم‌اند.
