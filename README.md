# BIT24 Demo Lab — داشبورد معاملات کاغذی

**فقط Demo. هیچ اتصال زنده، سفارش واقعی، واریز، برداشت یا ارسال تلگرام وجود ندارد.**
تمام قیمت‌ها، نمودار، نقدینگی، سیگنال‌ها و بازده‌ها «اطلاعات فرضی» هستند.

## اصلاحات جاری Backend + Frontend — v3

[گزارش تحویل و محدودیت‌های دقیق REAL](BIT24-REMEDIATION-FA.md). آمار دفتر حساب، کارمزد و کندل بسته، قفل روزانهٔ ۲۴ساعته، Panic و کارت‌های موبایل اصلاح شده‌اند. ۷۷ تست و ۱۵ بررسی مرورگر موفق‌اند. کلید DEMO/REAL درخواست آمادگی است؛ REAL بدون adapter رسمی بررسی‌شده همچنان قفل می‌ماند. بستهٔ جدید: `BIT24-QUANT-SAFETY-v3.zip`.

## شروع سریع

Node.js 22.12+ / 24 LTS:

```sh
npm ci
node scripts/setup-demo-env.cjs
npm run build
npm start
```

در `http://localhost:3000` توکن `DASHBOARD_API_TOKEN` فایل محلی `.env` را در فرم اتصال وارد کنید. این توکن فقط رمز دسترسی داشبورد است، نه کلید صرافی. آن را منتشر نکنید.

برای اجرای خروجی آمادهٔ ZIP، `npm ci --omit=dev`، فرمان setup و `npm start` کافی است.

## تست و بسته‌بندی

```sh
npm run typecheck
npm test
npm run build
npm run test:mobile
npm audit
npx cap sync android
npm run package:demo
```

تست مرورگر به محیط Linux سازگار نیاز دارد؛ از مرورگر headless داخل وابستگی npm استفاده می‌کند، نه گوشی واقعی. پروژه‌های مستقل و فایل‌های رسانه‌ای دیگر مخزن جزو این برنامه و بستهٔ تحویل نیستند.

## داده‌ها

حساب، موقعیت‌ها، تاریخچه، تنظیمات و رسیدهای idempotency در `data/demo-state-v2.json` روی **سرور** ذخیره می‌شوند. این پوشه محرمانه/محلی است و در ZIP یا Git قرار نمی‌گیرد. برای پشتیبان‌گیری، سرور را متوقف و فایل را کپی کنید. فایل خراب به حساب خالی تبدیل نمی‌شود؛ سرور با خطای مشخص متوقف می‌شود.

این ذخیره‌سازی فایل‌محور، تک‌پردازه و مخصوص آزمایش است؛ زیرساخت معاملات واقعی یا چندسروری نیست. خریدهای جدید فقط دستی و با هشدار هستند؛ حد ضرر، سود پله‌ای و trailing در سرور به‌صورت حفاظتی خودکار بررسی می‌شوند.
