# نُوا — پایانه هوشمند بازار

یک رابط وب فارسی، راست‌چین و سازگار با موبایل برای مشاهده سناریوهای نمونه و تمرین معامله‌گری. قابل نصب به‌صورت PWA در اندروید و دارای پوسته آفلاین.

## اجرا

از ریشه مخزن یک وب‌سرور اجرا کنید؛ برای نمونه:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

سپس آدرس را در مرورگر باز کنید. برای نصب روی اندروید، صفحه را در Chrome باز کنید و از منوی مرورگر «Install app / افزودن به صفحه اصلی» را انتخاب کنید. نصب PWA به HTTPS یا localhost نیاز دارد.

## محدودیت‌های مهم نسخه فعلی

- این پروژه فرانت‌اند نمایشی است؛ نمودار، قیمت‌ها، موجودی و پوزیشن‌های اولیه داده نمونه هستند و فید بازار زنده ندارند.
- آپلود تصویر صرفاً پیش‌نمایش می‌دهد؛ تحلیل تصویر یا بینایی ماشین پیاده‌سازی نشده، پس سیستم از تصویر سطحی را حدس نمی‌زند.
- ربات، سفارش‌ها، واریز و برداشت فقط در شبیه‌ساز داخل مرورگر کار می‌کنند. هیچ صرافی، کیف‌پول یا مسیر انتقال پول متصل نیست و معامله واقعی انجام نمی‌شود.
- برای نسخه زنده لازم است منبع داده قابل‌اعتماد، سرور امن، احراز هویت، مدیریت کلیدها و ریسک، بک‌اند سفارش‌گذاری و آزمون‌های امنیتی مستقل طراحی شوند. کلید API نباید در کد سمت کاربر قرار گیرد.
