# BIT24 AI TRADER PRO
### ربات هوشمند معامله‌گر ارز دیجیتال و طلای دیجیتال — طراحی‌شده ۱۰۰٪ از صفر و منحصراً برای صرافی Bit24

> **قوانین امنیتی قطعی سامانه:**
> - **انحصار کامل به صرافی Bit24 (`https://rest.bit24.cash`):** هیچ‌گونه اتصال به کیف پول‌های خارجی، شبکه‌های غیرمرتبط یا سایر صرافی‌ها وجود ندارد.
> - **مسدودسازی دائمی برداشت وجه (Zero-Withdrawal Policy):** اندپوینت برداشت وجه در سطح کلاینت و سرور مسدود شده است (`BIT24_WITHDRAWAL_FORBIDDEN`). هنگام ساخت کلید در پنل Bit24 هرگز تیک برداشت را فعال نکنید.
> - **قفل پیش‌فرض معاملات واقعی:** حالت `LIVE` به‌صورت پیش‌فرض خاموش است و تا زمان تأیید نهایی صریح کاربر هیچ معامله واقعی ثبت نمی‌شود.
> - **سلب مسئولیت شفاف:** هیچ سیگنال یا امتیازی در بازار رمزارز و طلای دیجیتال سود قطعی را تضمین نمی‌کند.

## ۱. امکانات اصلی سامانه

1. **اتصال رسمی و رمزنگاری‌شده به API صرافی Bit24 (CAPI v1/v2):**
   - پشتیبانی از هدر `X-BIT24-APIKEY` و امضای `HMAC-SHA256` برای اندپوینت‌های رسمی بازار، کندل (`ohclv`)، اوردربوک، موجودی کیف پول و سفارش اسپات.
   - ذخیره کلیدها با رمزنگاری `AES-256-GCM` در فایل محلی `.bit24-vault.enc` (خارج از سورس‌کد و Git) و WebCrypto در نسخه مستقل اندروید.
2. **موتور هوشمند شکارچی پامپ (`AI Pump Hunter`):**
   - پایش مداوم رمزارزهای بازار تومانی Bit24 با بررسی رشد حجم، قدرت خریداران، تغییرات `1m / 5m / 15m / 60m`، روند ۲۴ ساعته، شکست مقاومت، پولبک روی حمایت، `RSI(14)`، `MACD(12,26,9)`، `EMA20`، `EMA50` و `ATR(14)`.
   - جلوگیری هوشمند از خرید کورکورانه ارزهایی که قبلاً پامپ شده‌اند و تشخیص تله‌های پامپ و دامپ.
   - امتیازدهی `0` تا `100` در ۴ سطح دقیق: `<60` رد سیگنال، `60–74` فقط هشدار، `75–84` فرصت قابل بررسی، `85–100` سیگنال قوی برای آزمایش.
3. **مدیریت سرمایه حرفه‌ای و خروج پله‌ای (`Capital & Stepped Exit`):**
   - پیش‌فرض‌های قابل تنظیم: ۱٪ ریسک در هر معامله، حداکثر ۱۰٪ سرمایه در هر معامله (سقف ایمنی مطلق ۳۵٪ — ورود ۱۰۰٪ سرمایه در یک معامله برای همیشه ممنوع است)، حداکثر ۳ معامله هم‌زمان، سقف ۳٪ ضرر روزانه همراه با توقف خودکار.
   - حد ضرر اولیه `5%`، فعال‌سازی `Trailing Stop` پس از `+8%` سود با فاصله `3%` از سقف قیمت، و فروش پله‌ای: **۳۰٪ در `+10%`**، **۳۰٪ در `+20%`** و **۴۰٪ در `+35%`**.
4. **ماژول مستقل طلای دیجیتال (`GOLD AI TRADER`):**
   - بررسی اختصاصی قابلیت معامله واقعی `PAXG/IRT` (پکس گلد) و `XAUT/IRT` (تتر گلد) در Bit24 و تفکیک ۱۰۰٪ سرمایه، حد سود/ضرر و گزارش سود و زیان طلا از رمزارزها.
5. **ماژول امنیتی `SMART SECURITY` و تست `100+` معامله:**
   - فیلتر اسپرد بالا، نقدشوندگی کم، داده قدیمی، سفارش تکراری، قطعی اینترنت و مدارشکن خطای صرافی همراه با ثبت دقیق علت رد هر سفارش.
   - اجرای شبیه‌ساز حرفه‌ای کندل‌به‌کندل بدون نگاه به آینده (`Zero-Lookahead`) برای `100+` معامله با کسر کارمزد واقعی `0.2%` هر سمت و اسلیپیج + ۴ تست تزریق خطا.

## ۲. راهنمای نصب و راه‌اندازی سریع

### پیش‌نیازها
- `Node.js >= 20` و `npm`

### اجرای کامل سرور + پنل وب/اندروید
```bash
npm install
npm run typecheck
npm test
npm run build
npm start
```
سرور روی `http://0.0.0.0:3000` اجرا می‌شود و هم API پروکسی امن Bit24 و هم رابط کاربری دوزبانه (`FA` / `EN`) را سرویس می‌دهد.

---

## ۳. راهنمای اتصال امن به API صرافی Bit24

1. وارد حساب کاربری خود در وب‌سایت رسمی **Bit24** شوید و به بخش **مدیریت API** بروید.
2. یک کلید جدید بسازید و **فقط** دسترسی‌های زیر را بدهید:
   - خواندن اطلاعات بازار و کیف پول (`Read`)
   - معامله اسپات (`Spot Trade` — فقط در صورتی که بعداً قصد فعال‌سازی حالت واقعی را داشتید)
   - **مهم:** دسترسی **برداشت وجه (`Withdraw`) را هرگز فعال نکنید**.
3. در صورت داشتن IP ثابت روی سرور خود، آدرس IP سرور را در لیست سفید کلید Bit24 ثبت نمایید.
4. در برنامه روی دکمه **`API SETTINGS`** بزنید و کلید API و Secret Key را وارد کرده و دکمه **«ذخیره رمزنگاری‌شده و تست اتصال Bit24»** را بزنید.

## ۴. نصب روی گوشی اندروید (PWA فوری + ساخت فایل Native APK)

### روش اول: نصب مستقیم و بدون تحریم پیامک روی اندروید (PWA)
رابط برنامه دارای مانیفست استاندارد اندروید و Service Worker است:
1. لینک HTTPS برنامه را در مرورگر **Chrome** گوشی اندروید باز کنید.
2. روی دکمه طلایی **«نصب مستقیم روی اندروید (PWA)»** در بالای صفحه (یا گزینه `Install app / Add to Home screen` در منوی کروم) بزنید تا برنامه به‌صورت تمام‌صفحه با آیکون اختصاصی `BIT24 AI TRADER PRO` روی صفحه اصلی گوشی نصب شود.

### روش دوم: کامپایل بسته نصبی بومی `.apk` با Capacitor
در محیط فعلی سندباکس ابری، کامپایلرهای `JDK 17` و `Android SDK / Gradle` نصب نیستند (و طبق اصل صداقت، هیچ فایل `.apk` ساختگی تولید نشده است). برای بیلد فایل رسمی `app-debug.apk` روی سیستم خود که دارای Android Studio / JDK 17 است، کافی است دستور زیر را اجرا کنید:
```bash
npm run android:apk
```
فایل خروجی در مسیر `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.
