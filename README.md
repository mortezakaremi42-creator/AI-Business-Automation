# پروژه حرفه‌ای Bit24 Smart Trader AI + Gold

پلتفرم معامله‌گر هوشمند، مدیریت ریسک و داشبورد فارسی راست‌چین قابل مدیریت از روی **گوشی اندروید (PWA)** و **بک‌اند دائمی Node.js / Docker** با دو ماژول مستقل:

1. **ماژول مستقل رمزارزهای اسپات بیت‌۲۴ (`SPOT_CRYPTO` + زیرماژول میم‌کوین `MEME_HUNTER`)**: متصل به مستندات رسمی CAPI v1/v2 صرافی بیت‌۲۴ (`https://docs.bit24.cash`).
2. **ماژول مستقل طلای دیجیتال در بیت‌۲۴ (`DIGITAL_GOLD`)**: تحلیل و سفارش‌گذاری رسمی روی توکن‌های طلای دارای پشتوانه فیزیکی **`PAXG` (پکس‌گلد)** و **`XAUT` (تترگلد)** در اسپات بیت‌۲۴، همراه با مقایسه حباب دلاری نسبت به نرخ مرجع انس جهانی (`XAU/USD`) و تفکیک کامل سرمایه و سود/زیان از رمزارزها.

> **اصل شفافیت و ریسک:** هیچ سودی در بازارهای مالی تضمین‌شده نیست و هیچ الگوریتمی قادر به پیش‌بینی قطعی کف بازار یا پامپ آینده نیست. حد ضرر نیز در نوسان‌های شدید اجرای دقیق در همان قیمت را تضمین نمی‌کند (احتمال اسلیپیج). تا زمان موفقیت تست‌های حالت آزمایشی (Paper Trading)، کلید واقعی وارد نکنید.

## معماری امنیتی (مرحله هشتم)

- **نگهداری کلید فقط در سمت سرور (`Server-Only Vault`):** کلیدهای API هرگز در کد فرانت‌اند، حافظه مرورگر (`localStorage`)، فایل عمومی یا مخزن Git ذخیره نمی‌شوند. در بک‌اند با الگوریتم `AES-256-GCM` + کلید مشتق‌شده `scrypt` رمزنگاری شده یا از فایل محیطی `.env` سمت سرور خوانده می‌شوند.
- **مسدودسازی قطعی برداشت وجه:** مسیر `/lite/capi/v1/withdraw/submit` هم در کلاینت API و هم در فایروال سرور با خطای `403` مسدود است. هنگام ساخت کلید در پنل بیت‌۲۴ نیز **هرگز مجوز برداشت وجه را فعال نکنید**.
- **تأیید رسمی موجودی و سفارش:** موجودی واقعی حساب فقط پس از دریافت پاسخ موفق از اندپوینت `/asset/capi/v1/wallet/assets/total` نمایش داده می‌شود و هیچ سفارش واقعی بدون دریافت `order_id` معتبر از صرافی ثبت‌شده تلقی نمی‌گردد.
- **محدودیت نرخ درخواست و احراز هویت مدیر:** پشتیبانی از `ADMIN_ACCESS_TOKEN` در هدر `X-Admin-Token`، محدودکننده نرخ درخواست به ازای هر IP، قفل جلوگیری از تکرار سفارش (`Idempotency Lock`) و سانسور خودکار توکن‌ها در لاگ‌ها.

## قوانین پیش‌فرض مدیریت ریسک (مرحله پنجم — قابل تغییر در تنظیمات)

- **ریسک هر معامله:** حداکثر `۰.۵٪` سرمایه تخصیص‌یافته آن بخش.
- **حداکثر ریسک مجموع موقعیت‌های باز:** `۲.۰٪` کل سرمایه تخصیص‌یافته.
- **توقف معاملات جدید در زیان روزانه:** `۲.۰٪`.
- **حداکثر موقعیت باز هم‌زمان:** `۳` موقعیت.
- **اهرم و فیوچرز:** در نسخه اول به صورت پیش‌فرض **خاموش (`OFF`)**.
- **توقف خودکار (`Circuit Breaker`):** توقف فوری معاملات جدید در صورت داده قیمتی غیرعادی یا ۳ خطای متوالی ارتباطی API.

## راهنمای دقیق اجرا روی رایانه و گوشی اندروید

### ۱. اجرای کامل با بک‌اند امن ۲۴ ساعته (پیشنهادی برای اتصال کلید API)

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. ساخت فایل تنظیمات محیطی سمت سرور از روی نمونه بدون اطلاعات محرمانه
cp .env.example .env
# مقادیر BIT24_VAULT_SECRET و در صورت تمایل ADMIN_ACCESS_TOKEN را در .env تنظیم کنید

# ۳. اجرای تست‌های خودکار و بررسی صحت کدها
npm run typecheck
npm test

# ۴. اجرای سرور توسعه یا پروداکشن روی پورت 3000 (قابل دسترسی از مرورگر گوشی در شبکه یا سرور ابری)
npm run build
npm start
```

سپس آدرس سرور (مثلاً `https://your-server-domain.com` یا `http://<SERVER-IP>:3000`) را در مرورگر **Google Chrome گوشی اندروید** باز کنید و از منوی کروم گزینه **«Install App / Add to Home screen»** را بزنید.

### ۲. اجرای با Docker Compose

```bash
cp .env.example .env
docker compose up -d --build
```

### ۳. روش واقعی ساخت فایل نصبی `APK` اندروید (Trusted Web Activity)

این پروژه دارای `manifest.webmanifest`، آیکون‌های استاندارد `192/512 maskable` و `Service Worker` کامل است. اگر علاوه بر نصب مستقیم PWA، نیاز به فایل باینری `.apk` امضاشده دارید، روی سیستمی که `JDK 17` و `Android SDK` نصب دارد دستورات زیر را اجرا کنید:

```bash
npx @bubblewrap/cli init --manifest=https://YOUR-HTTPS-DOMAIN/manifest.webmanifest
npx @bubblewrap/cli build
# خروجی: فایل app-release-signed.apk آماده نصب مستقیم روی اندروید
```

## قابلیت‌های دارای برچسب شفاف «تکمیل نشده»

1. **اتصال معاملاتی مستقیم به کارگزار جهانی فارکس (`XAU/USD`) — `تکمیل نشده`:** معامله خودکار طلا منحصراً روی توکن‌های طلای رسمی بیت‌۲۴ (`PAXG` و `XAUT`) از طریق API رسمی بیت‌۲۴ انجام می‌شود و نرخ `XAU/USD` صرفاً مرجع تحلیلی مقایسه حباب است.
2. **کامپایل باینری `.apk` در محیط لینوکس ابری فعلی — `تکمیل نشده`:** به دلیل عدم نصب `Android SDK / Gradle` در سندباکس ابری، خروجی آماده به صورت **وب‌اپلیکیشن قابل نصب اندروید (PWA)** ارائه شده و دستور دقیق تولید APK با Bubblewrap در بالا درج گردیده است.
3. **معاملات فیوچرز دائمی — `تکمیل نشده`:** صرافی بیت‌۲۴ بازار فیوچرز دائمی ندارد و معاملات اهرمی نیز طبق قانون مرحله پنجم در نسخه اول خاموش است.
