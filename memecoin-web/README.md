# رادار میم — PWA آزمایشی

نسخهٔ وب مجزا از `memecoin-mobile` و Bit24. رابط فارسی RTL با نصب روی صفحهٔ اصلی در مرورگرهای سازگار، manifest، آیکون PNG، service worker و راه‌اندازی آفلاین پس از اولین بارگذاری کامل.

**همهٔ موجودی‌ها، قیمت‌ها، امتیازهای اسکن و معاملات فرضی‌اند.** هیچ اتصال کیف پول، درخواست seed، واریز، امضا، ارسال تراکنش واقعی، اسکن زنده یا WireGuard بومی وجود ندارد. صفحهٔ Settings این محدودیت‌ها را نشان می‌دهد. این PWA تبدیل کامل خدمات Flutter به مرورگر نیست و جای APK ممیزی‌شده را نمی‌گیرد.

## اجرا

Node.js بدون dependency:

```sh
node server.mjs
# 0.0.0.0:4173 — PORT قابل تنظیم است
```

برای نصب، HTTPS لازم است (localhost فقط برای توسعه). لینک HTTPS را در Chrome گوشی مستقیماً باز کنید، سپس ⋮ ← Install app / Add to Home screen. در Safari: Share ← Add to Home Screen. امکان نصب به مرورگر/تنظیمات دستگاه بستگی دارد؛ محیط iframe ممکن است گزینهٔ نصب را نشان ندهد. آدرس پیش‌نمایش Arena موقت و وابسته به فعال‌بودن محیط است، نه هاست دائمی. برای انتشار پایدار فایل‌های static را روی HTTPS شخصی قرار دهید؛ `server.mjs` فقط سرور نمونه است.

## رفتار

فروش تکی، Panic Sell، توقف پایش آموزشی، تاریخچه، تنظیمات و reset فقط localStorage مرورگر را تغییر می‌دهند. نمودار نمونه ثابت است و تاریخچهٔ مالی واقعی نیست. service worker فقط assetهای همین برنامه را cache می‌کند. هیچ credential یا private key وارد نکنید. دادهٔ فرضی با حذف دادهٔ سایت پاک می‌شود.
