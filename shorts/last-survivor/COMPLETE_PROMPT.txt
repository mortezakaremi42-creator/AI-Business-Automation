═══════════════════════════════════════════════════════════════════════════════
CAPCUT ANIMATION TIPS
═══════════════════════════════════════════════════════════════════════════════

1. KEYFRAME ANIMATION:
   - Use keyframes for smooth character movement
   - Animate position, scale, and rotation
   - Create walk cycles by alternating leg/arm positions

2. CAMERA MOVEMENTS:
   - Zoom in/out for dramatic moments
   - Pan left/right for tracking shots
   - Shake effect for action scenes
   - Slow-motion for key moments (jumping, crashes)

3. TRANSITIONS:
   - Quick cuts for action (0.2-0.3 seconds)
   - Fade to black for scene changes
   - Dissolve for time passing

4. SOUND DESIGN:
   - Layer multiple sound effects
   - Sync footsteps with character movement
   - Add ambient sounds (wind, distant zombies)
   - Use music to build tension

5. CHARACTER ANIMATION:
   - Create 4-6 poses per scene
   - Use motion blur for fast movement
   - Add secondary motion (hoodie fluttering, hair moving)
   - Animate facial expressions (eye movement, mouth if visible)

6. ENVIRONMENT:
   - Add particle effects (dust, smoke, debris)
   - Animate background elements (flickering lights, moving shadows)
   - Use parallax scrolling for depth
